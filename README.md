# TIDELINE · 타이드라인

방향키 또는 터치로 바늘을 직접 움직이는 한국어 낚시 게임 프로토타입. 외부 패키지 없이 Node.js 20 이상에서 실행합니다.

```sh
npm start
```

브라우저에서 http://localhost:3000 을 엽니다. 모바일에서는 같은 네트워크에서 PC의 IP 주소와 포트 3000으로 접속할 수 있습니다. 방화벽이 허용해야 합니다.

## 플레이

참고 이미지의 그래픽 방향을 따라 노을 호수·숲 배경, 낚시꾼과 목조 보트, 나무·황동 버튼, 청록색 도감 패널과 희귀도 별 표시를 적용했습니다. `pixel-theme.css`가 기존 레이아웃에 공통 테마를 입히며 모바일에서는 하단 메뉴와 두 열 도감을 사용합니다. ImageGen으로 만든 `assets/sunset-lake.png`와 `assets/fishing-props.png`는 `visual-assets.js`에서 표시하고, 제작 프롬프트는 `assets/visual-direction.prompts.md`에 보관합니다. 대기 화면은 호수 전경, 투척 후에는 물고기·바늘이 잘 보이는 수중 화면으로 전환합니다.

- **낚시**: 던지기 → 방향키/WASD 또는 바다를 누르고 끌어 바늘 이동 → 물고기에 가까이 다가가면 바늘을 감지해 반응하고 포획. 성공하면 미끼 1개를 소모하고 바늘과 물고기를 수면으로 자동 회수합니다. 한 투척당 한 마리만 잡습니다. 빈손 회수나 시간 초과에는 미끼를 소모하지 않습니다. 모바일 방향 패드도 지원합니다. 한 번의 조업은 60초입니다. 잡은 물고기는 즉시 코인과 경험치로 정산됩니다.
- **어종·그래픽**: 총 20종입니다. 사용자 제공 원본 `assets/fish-atlas.png`의 10종에 ImageGen으로 같은 픽셀 스타일의 `assets/fish-atlas-extra.png` 10종을 추가했습니다. 기존 도감 순서 뒤에 잉어·피라미·쏘가리·가물치·농어·고등어·참돔·넙치·해마·청새치가 표시됩니다. 제작 프롬프트는 `assets/fish-atlas-extra.prompt.md`에 보관합니다. 두 시트를 `fish-atlas.js`에서 프레임으로 나눠 낚시 화면과 도감에 표시하며, 원본 파일과 기존 어종 ID·저장 기록은 유지합니다. 가장자리와 연결된 검은 여백만 로딩 시 캔버스에서 투명 처리하고, 세로로 긴 해마는 프레임 안에 맞춰 표시합니다. 모든 어종은 고정 활동 루틴과 보이지 않는 서식 영역를 가지며, 영웅 어종은 1회, 전설 어종은 2회 도주 후 재접근합니다. 희귀도·활동 수심은 게임 설정입니다.
- **장비**: 낚싯대 3종, 소비 미끼 5종(10개 묶음 15/35/70/45/110 코인), 공통 강화 10단계. 처음 새우 20개를 제공합니다. 미끼는 돌진 속도와 도주 후 대기에 영향을 줍니다. 조업 코인과 낚시 코인은 같은 지갑으로 합산됩니다. 공방의 재접근 연구는 120 + 현재 단계 × 90 코인으로 구매하며 10단계까지 단계당 대기 시간을 6.5% 줄입니다. 미끼와 고요한 바늘 스킬의 효과를 함께 적용하고 최저 대기는 0.65초입니다.
- **스킬**: 유인/조작/성장 세 갈래에 3개씩, 최대 3개 장착. 처음 2 SP, 레벨업마다 1 SP. 선행 스킬 해금 필요. 물결의 속삭임은 스페이스 또는 스킬 버튼으로 발동하며 5초 돌진 강화·도주 대기 회복 가속 / 18초 재사용입니다.
- **방치**: 자동 조업선이 분당 코인을 생산합니다. 게임을 닫은 시간도 반영하며 보관은 최대 8시간. 조업선은 6레벨까지 성장합니다. 자동 조업은 물고기 도감이나 경험치를 올리지 않습니다.
- **저장**: 같은 브라우저의 localStorage에 장비, 스킬, 코인, 도감, 조업 시각을 저장합니다. 브라우저 데이터를 지우면 초기화됩니다. 다른 브라우저나 기기와 동기화하지 않습니다. 네트워크 없이도 게임은 작동하고, 웹 폰트는 시스템 글꼴로 대체됩니다.

보스전은 보류되어 있으며, 현재 코인·시간은 브라우저에서 계산하는 싱글 플레이 프로토타입입니다. 모바일 배포/PWA, 계정·서버, 실제 결제는 포함하지 않습니다.

## 검증

```sh
npm test
```

경제·저장 규칙은 `game-core.js`, 투척·추적·포획·도주·회수 상태는 `fishing.js`, 화면·입력은 `app.js`, 직접 만든 픽셀 스프라이트와 바다 렌더링은 `pixel-art.js`, 반응형 스타일은 `style.css`에 있습니다. 바다·배·낚시꾼·바늘·산호를 저해상도 캔버스로 그린 후 필터 없이 확대합니다. 테스트는 방치 수익으로 미끼 구매, 포획당 정확히 1개 소모, 자동 회수, 도주·재접근, 재접근 연구 효과, 활동 범위와 패턴 결정성, 장비 효과, 스킬 제한, 보상/레벨업, 방치 상한, 저장 복구를 검증합니다.

기존 코인·장비·미끼·스킬을 유지합니다. 이전 어종 기록은 같은 내부 ID의 새 그림 항목(멸치→붕어, 블루탱→송어, 가오리→메기, 황다랑어→참치)으로 이어집니다. 흰동가리는 그대로 유지하고 새 5종은 미발견으로 시작합니다.

기존 영구 미끼 저장은 소비 재고로 1회 이전합니다(새우 20개, 이전에 구매한 특수 미끼 각각 10개). 버전 2부터 재고 0도 그대로 저장·복원하며 재접근 연구 단계도 저장합니다.

물고기는 보이지 않는 서식 영역을 순찰합니다. 바늘 감지는 영역 진입이 아닌 현재 물고기와 바늘 사이 거리(기본 110, 유인 스킬 장착 시 148.5)로 판정합니다. 추적 중에는 감지 거리의 두 배를 넘으면 관심을 잃고 원래 영역의 순찰 경로로 복귀합니다. 추적·도주 중에도 영역을 벗어나지 않습니다.

화면은 5:3 비율을 유지하며 표시 영역과 devicePixelRatio에 맞춘 캔버스를 사용합니다. 수중 화면·도감·장비·조업선은 이미지 보간 없이 다시 그립니다. 감지 거리에 들어온 모든 물고기는 동시에 반응하고 각자의 영역 안에서 추적합니다. 바늘에는 한 마리만 걸리며 포획 시 미끼 1개 소모 후 자동 회수합니다. 여러 마리가 반응하면 HUD에 반응 수를 표시합니다.
